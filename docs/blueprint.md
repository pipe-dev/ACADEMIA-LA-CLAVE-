# **App Name**: Perfect Pitch

## Core Features:

- Audio Capture: Microphone Input: Capture audio input from the user's microphone.
- Pitch Analysis: Real-time Pitch Detection: Analyze the audio input to determine the current pitch being played or sung.
- Note Visualization: Note Display: Show the detected note (e.g., A, B, C#) on a clear visual display.
- Frequency Display: Frequency Display: Display the detected frequency in Hertz (Hz).
- Tuning Guide: Tuning Indicator: Provide a visual indicator (e.g., a needle or bar) to show how close the detected pitch is to the target note.
- Chromatic Tuning: Chromatic Scale Support: Detect and display all 12 notes of the chromatic scale (A, A#, B, C, C#, D, D#, E, F, F#, G, G#).

## Style Guidelines:

- Primary color: Forest green (#388E3C), evokes a sense of precision and natural harmony.
- Background color: Light beige (#F5F5DC), offering a neutral, unobtrusive backdrop.
- Accent color: Soft Gold (#DAA520), providing visual cues and indicating perfect pitch.
- Body and headline font: 'Inter', a grotesque-style sans-serif that is modern, machined, objective and neutral.
- Use minimalist, clear icons to represent settings and status (e.g., microphone, note display).
- Center the tuning indicator prominently for immediate feedback. Keep secondary information (frequency) visually separate.
- Use smooth transitions for the tuning indicator and note display to create a polished and responsive user experience.
