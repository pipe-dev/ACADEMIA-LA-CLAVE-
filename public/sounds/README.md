## Archivos de Sonido de Referencia

Para una experiencia personalizada, esta aplicación puede utilizar tus propios archivos de audio como tonos de referencia.

Por favor, añade dos archivos de audio de alta calidad en esta carpeta:

1.  **`masculino-C4.mp3`**: Un archivo de audio de una voz masculina cantando la nota **Do central (C4)** de forma clara y sostenida.
2.  **`femenino-C4.mp3`**: Un archivo de audio de una voz femenina cantando la nota **Do central (C4)** de forma clara y sostenida.

**Importante:**
- Los nombres de los archivos deben ser exactos.
- La aplicación utilizará estos archivos y ajustará su tono para generar todas las demás notas necesarias en los ejercicios.
- Si estos archivos no se encuentran, la aplicación utilizará un tono generado por defecto.
